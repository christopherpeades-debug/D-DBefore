# D&D Before

Interactive D&D 3.5 character sheet — **Keen 2.03** (C# / WPF), successor to the Python app in this repository.

## Install

Download the latest release from [Releases](https://github.com/christopherpeades-debug/D-DBefore/releases):

| File | Who it's for |
|------|----------------|
| **`DnD_Before_v2.03_Setup.exe`** | New install, or **Python D&D Before** users upgrading to Keen (asset keyword `Setup`) |
| **`DnD_Before_Keen_v2.03_Portable.zip`** | Already on Keen — launcher **Update** overlays files with a progress bar (keyword `Portable`) |

### After install

1. Run **`D&D Before Launcher.exe`** first.
2. **Launch** starts **D&D Before Keen**.

Current version: **v2.03**

## Updates

| You currently run | What the updater does |
|-------------------|------------------------|
| **Python D&D Before** | Downloads **Setup.exe** from the latest GitHub Release |
| **Keen + Launcher** | **Update** prefers **Portable.zip** (keeps Characters and sync settings) |
